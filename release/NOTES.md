# RLLM Lab 1793167000 — shared harness web search

Web search now runs in the harness for local models and all supported remote model protocols. No MiniMax account or additional search key is required. Leave App settings → Network services → Web access → Custom search URL blank to use Mwmbl anonymous search, with DuckDuckGo HTML as the distinct fallback. Optional MiniMax provider-hosted search remains separate.

One approved search keeps its exact query, original conversation and model/worker connection. Each source is attempted at most once. Structured titles, URLs and snippets return to that same model; valid zero-result observations allow a newly reviewed focused query. Verification pages and navigation-only content are not treated as results. Custom services retain their exact endpoint and isolated credentials. Original Rust implements the plan, parsing and continuation; no third-party search program is installed.

Independent host checks cover all four supported model protocols in ordinary and recursive paths, worker credentials, cancellation, stale callbacks, parser bounds, empty results and source fallback. Actual loopback HTTP checks and captured public-response replays pass. Public research found results for a focused game-title query and zero results for the original long query; the independent live transport attempt failed at DNS. These checks do not establish installed Android or live-provider acceptance.

All24 signed runtime payloads match an independent rebuild of both native ABIs/JNI, DEX and resources. All84 build inputs remained unchanged; stable signer, v2/v3 signatures, CRC, ZIP16KiB and both ELF alignments pass. Prior MiniMax, stream, reading/scroll, history, attachment and native inspection features remain preserved. Full-project/device acceptance and the previously disclosed archive-import independent review remain open.

Install over existing Lab without uninstalling or clearing data. com.local.client.lab / 0.1-lab.1793167000. APK 6256601 bytes, SHA256 bec24e200189d75eeff718d5e47230f3fa93c698e5a6bf3ec4a9b7cb23c66299.

Each of the two attempts has the existing 120-second native deadline, not a shared 120-second limit.
