# Current implementation

Voice review now reports its actual waiting state, preserves unexecuted proposals when dismissed, pauses cleanly after rejection and starts a fresh microphone only on explicit resume. Actual service admission advances recognition/synthesis status, and manual transcription stays in the composer. Audio route disconnection and speech focus loss now stop owned foreground capture/playback, invalidate the current voice session and preserve unrelated text/local work and in-flight primary answers. Speech explicitly pauses for transient ducking, and stale route/focus callbacks cannot stop a new owner. Scene rasterization now uses bounded shared CPU workers, disjoint row bands, preserved draw order and deterministic pixels. Measured CPU and memory limits retain a single-worker fallback, and queued/active cancellation releases owned workers before returning. Packaging validates complete aligned payload hashes/lengths/CRC and retries alignment at most once before signing. Returned GLB triangle geometry now has an owned interactive in-app software viewport with Rust accessor, sparse-data, hierarchy, transform, material and source validation. Native orbit, zoom and reset controls present actual depth-tested geometry. Unsupported scenes retain their original files for export. Optional foreground spoken interruption now uses explicit consent, device echo control and the same Rust PCM capture across playback interruption, preserving leading speech. Saved microphone review controls now reach their actual settings. Unsupported echo control retires only the optional watch; explicit Speak now and ordinary text remain available. Direct binary service submissions now stream complete 200/201 responses to owned files, with configured limits, exact statuses, scoped fallback and expiry cleanup. Accepted, partial, redirected, truncated or uncertain submissions are not replayed. Selected files up to 64 MiB now import and upload in bounded chunks through configurable binary, multipart and JSON requests, with file ownership, shared storage reservations and scoped GET upload refusal. Optional voice conversation now supports explicit Speak now interruption, immediate Stop for pending playback and stale callback isolation. Missing CPU metadata discovers bounded multicore host task concurrency. Optional generic S256 authorization includes owned automatic refresh and browser-flow recovery while retaining API-key settings. Read-only ACP v1 sessions share actual workspace operations. Configurable recognition/synthesis, image/video/scene/document routes, fallbacks, jobs, streamed artifacts, ordinary text, local work and captured primary/child returns remain part of the same app. Extra services remain optional.

Setup, mappings, job behavior and limits: [SERVICES.md](SERVICES.md). The established text, investigation, web, file, storage, MCP/A2A and delegation paths remain part of the same app.
