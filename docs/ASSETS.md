# App assets

The APK includes two backgrounds in res/drawable-nodpi: wallpaper_dark.webp and wallpaper_light.jpg. Both were visually inspected for this release and have no visible watermark or text branding.

The icons are Android vector resources in res/drawable. Interface labels and diagnostic drawings are generated by the app's core and Android controls. Required runtime license notices are packaged under assets.

Earlier illustrative screen prompts and their asset notes are preserved in the preceding source snapshot. The current source describes the shipped assets.
