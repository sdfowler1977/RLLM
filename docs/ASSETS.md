# Visual assets and notices

The two documentation images in `docs/images/` were generated specifically for this publication using the built-in image-generation tool. They are interface illustrations, not captured application screenshots or measured benchmarks. All displayed settings, conversations and numbers are fictional. They contain no personal endpoint, API key or medical conversation.

`overview-preview.png` illustrates chat, the three-part footer and analytics. `setup-preview.png` illustrates the connection and routing forms. Exact widget geometry and some decorative elements are illustrative; the APK's native UI is the implementation authority.

Prompt specifications are recorded in `IMAGE-PROMPTS.md`. No user screenshot was edited or published. Any later supplied screenshots should be inspected for addresses, account names, keys, conversation text, notifications and image metadata before publication. Use a fictional demonstration conversation and connection where possible; do not rely on a translucent blur over sensitive text.

The app's dark wallpaper came from the owner's Strata Monitor project and retains its MIT notice in `notices/strata-monitor-MIT.txt`. The supplied light wallpaper was owner-selected project artwork. Product vector icons are retained from the Android source. Runtime notices are in `notices/runtime.html` and remain packaged with the APK. These notices do not establish a new project-wide license for RLLM.
