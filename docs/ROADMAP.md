# Product completion

The agreed goal is the complete RLLM product. A passing feature check, signed candidate or published archive does not close the broader work. Preserve the original app, optional provider-neutral services, native UI, intrinsic investigation process and existing data formats. Implementation and acceptance remain separate. This plan records the original cumulative scope and does not replace it with a narrower voice-only contract.

| Area | Current implementation | Remaining work |

| Media and documents | Generic image/video/scene/document service routes, uploads, returned artifacts, tracked jobs, streamed downloads, previews/exports | Interactive scene viewing, broader capture and document processing; preserve provider-neutral server integration and optional behavior |

Next implementation order: current safety/data-loss defects, broken integration, required missing protocol/storage/voice capabilities, deeper analysis/resource work, then current package and device/service acceptance.
