# Investigation in command handling

RLLM integrates investigation into ordinary requests, assigned tasks, callable children, refinement, native controls and the JSON-lines controller. The shared process connects questions, plans, source observations, interpretations, finite checks and implementation decisions.

Open Investigation for file/folder inspection, comparison, capture, saved observations, hypotheses, experiments and reconstruction. The question/design view manages the plan, findings, requirement assessments and reviewed export. Agent settings adds your chosen guidance and saved skills.

Typed source evidence retains BinarySource/Encoding nodes, declared mappings, code/data labels, ELF relocation records, PE image base-relocation declarations and encoded branch relationships. Each record identifies source coordinates, captured bytes, retained/omitted counts and its representation digest. Queries, native views and exports use the same records.

The model configuration catalog supplies connection identities and callable-agent routes automatically. Reviewed children return their actual response or error to the captured parent, with controller status and linked question identity.
