## Internet and investigation

Manual search works without a model. Local and remote model routes share the harness search/read tools and return evidence to the original ordinary or recursive request. Blank search settings select the finite built-in source chain; custom endpoints and optional provider-hosted search remain separate. Verification/error pages are not successful results. Current host checks exercised live source results in ordinary and recursive flows; installed-device execution remains unverified.

The original Rust engine shares selected file/folder inspection and comparison, retained evidence, hypotheses, observational experiments, byte/specification reconstruction, supported source/data/media/binary observations and page capture across ordinary, recursive, manual and implemented headless paths. No separate REA installation or external analysis computer is required.

Supported remote HTML/CSS/PNG capture produces actual pixels with explicit resource and execution limits. The page compiler/evaluator supports a selected inline-program, array/plain-object and DOM subset. It is not a complete browser or full language implementation.
